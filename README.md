# Mafia — Shadow Conflict 🎭

لعبة مافيا جماعية (حتى 10 لاعبين)، كل واحد يلعب من تليفونو عبر المتصفح.

## التشغيل

```bash
npm install
npm start
```

السيرفر كيطبع عنوانين: `localhost` للكمبيوتر، و `http://192.168.x.x:3000` للتليفونات (خاصهم يكونو على **نفس الواي فاي**).

### التجريب بلا 10 ناس

```bash
MIN_PLAYERS=6 npm start        # Windows (PowerShell):  $env:MIN_PLAYERS=6; npm start
```

(من 5 لـ 10. الأدوار كتتوزع بالترتيب: زعيم، مافيا، محقق، طبيب، جاسوس، حارس، ثم المواطنين.)

## اللعب من برا الدار (أونلاين)

خاص خدمة كتدعم Node + WebSocket (Render, Railway, Fly.io...). **ماشي** Vercel/Netlify (serverless).
الأمر ديال التشغيل: `npm start`، والبورت كيجي من `PORT` تلقائياً.

## القواعد المطبقة

- **الليل**: الزعيم يختار الضحية (+ يخطف واحد اختيارياً)، المافيا تقترح، الطبيب يعالج، الحارس يحمي، المحقق يحقق، الجاسوس يتجسس.
- **الحارس**: إلا حمى الضحية، كيموت بلاصتها.
- **الطبيب**: يقدر يعالج راسو، ولكن ماشي نفس اللاعب ليلتين متتاليتين.
- **المحقق**: الزعيم كيبان ليه مواطن. **الجاسوس**: كيعرف غير واش هو الزعيم.
- **النهار**: نقاش (شات) + تصويت. المخطوف ما يهضرش ولا يصوت. التعادل = ما تسجن حتى واحد.
- **الربح**: المدينة إلا ماتت المافيا كاملة. المافيا إلا ولاو عددهم >= عدد المدينة.
